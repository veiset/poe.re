Pseudonymous usage analytics

When you select, create, rename, import, export, or delete a profile; create or
delete a favorite; select a language; or click the Trade button, the site records a usage event. At
most once per 24 hours while the site is used, it also records the current
language and the total number of profiles and favorites stored in the browser. A
failed profile import records only a general failure category, not the imported
content. Events can include the profile name, profile and favorite counts,
game, favorite type and page, selected language, and country.

The site generates a random identifier and stores it in your browser's local
storage so events from that browser can be counted together. It is not linked
to an account or email address; profile names are free-form text chosen by the
user. The custom usage event does not contain your IP address. Cloudflare
processes the request and supplies the country code under Cloudflare's
applicable privacy terms. Usage events are retained for the period configured
in Cloudflare Workers Observability.
